# IA-Skills-claude

Marketplace personal de skills para [Claude Code](https://claude.com/claude-code).

## Instalar

```
claude plugin marketplace add hmedinas/IA-Skills-claude
claude plugin install base_net10@ia-skills-claude
claude plugin install base_nuxt4@ia-skills-claude
```

## Skills

- **base_net10** — Genera un backend .NET 10 (Clean Architecture 6 capas, MediatR, Dapper, JWT, Serilog, Swagger).
- **base_nuxt4** — Genera un starter Nuxt 4 (PrimeVue + Tailwind + Pinia, login mock, theming, dark mode).
